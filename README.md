# 🎵 CFMI Planning Bot

Un bot Discord permettant d’afficher le planning du CFMI et les anniversaires des membres.

## Commandes disponibles
- `/today` — Affiche les événements du jour
- `/tomorrow` — Affiche les événements de demain
- `/planning` — Affiche les événements pour une date donnée
- `/search` — Recherche d’événements dans le planning
- `/add_birthday`, `/list_birthdays`, `/del_birthday`

## Installation locale
```bash
pip install -r requirements.txt
python app.py
